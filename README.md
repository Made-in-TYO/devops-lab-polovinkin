## План изучения DevOps

1. Освоить Git: коммиты, ветки, слияние.
2. Научиться работать через Pull Request по модели GitHub Flow.
3. Разобраться с автоматизацией проверок в GitHub Actions.
4. Изучить контейнеризацию в Docker.
5. Собрать полный цикл CI/CD.
6. Познакомиться с мониторингом и логированием.
